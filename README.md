直接 Ctrl/Cmd + P 就行。页面自带打印样式：自动转白底黑字，去掉按钮、顶部滚动条和首屏点阵画，适合打印留档。装箱的三维图、分层图和路线图会以静态结果一起打印，联系区深色卡片会自动转成白底描边。

## 设计说明（2026-09 重做）

视觉参考 **MiMo 官网**（mimo.mi.com）的纸感编辑风，融合 **StepFun 官网**（stepfun.com）的柔和暖白与淡蓝点缀：

- **配色**：暖白纸底 `#F6F4EE` + 墨色文字 `#151614`，背景有三块极淡的色浴（暖杏 / 淡蓝 / 灰绿）；点缀色是柔和的雾蓝 `#5B8FD9`，只用在活体指示、高亮等小元素上。没有深色发光、没有渐变霓虹。
- **首屏标题**：居中大标题打字机效果——「复杂需求 / 可靠交付」，末尾一个闪烁下划线光标；黑色胶囊主按钮 + 描边次按钮。
- **首屏视觉**：一块圆角大面板，内容是**品牌标识（山峰折线）的字符放大版**——和导航栏 logo 同一个形状，画法参考 MiMo 官网的字符蝴蝶：山体内部用一行行小号等宽字符铺满（PYTHON / SQL / RAG / AGENT / 知识库 / 审批流…），脊线用点描出、峰顶有圆头关节点，边缘与底部渐隐。**鼠标划过时附近字符会放大、提亮并轻微让开**（类似 DeepSeek 官网点鲸的交互）。"减少动态效果"时只画一帧静态。
- **科技感的来源**：等宽字体（编号、步骤、指标、联系方式）、点阵生成艺术、黑底滚动公告带、克制的入场动画——不靠彩色发光。
- **四条服务线**（卡片头图各自贴合内容）：
  1. 数据分析——折线图线稿
  2. Web 系统开发——浏览器窗口线稿
  3. 小程序 / App——手机 + 平板线稿
  4. AI 应用与算法——思维链路节点线稿（知识库 RAG、AI Agent、智能客服、组合优化、图像识别）
- **案例区**：
  - 观鸟小程序：真实照片版界面（`ui/bird.html` 重新截图嵌入，预览底色与页面背景一致，不再是黑底）；
  - 三维装箱：页面内**实时运行**的货架式装箱算法——等距三维装载结果 + 分层展开图同源生成，悬停可跨图定位同一件货物；
  - 多点位路线规划：页面内实时运行**贪心 + 随机重启**，给出多条候选路线，里程按 haversine 球面距离计算；点击地图可增删观测点，路线实时重算；
  - 知识库问答 · 智能客服：自设的 WeKnora 风格前端——左侧知识库文档列表、右侧问答界面（出处标注、快捷提问、打字机输出，预设问答可交互）；
  - 授信贷款流程跟踪系统：已脱敏的后台界面截图。
- **联系区**：整块墨色圆角面板收尾，号码/邮箱用等宽字体。
- **字体**：只用系统字体（苹方 / 微软雅黑）+ 系统等宽字体，不加载外网字体，保证内网和断网环境不掉样式。
- **动画**：只用 `transform` 和 `opacity`，不触发重排版；滚动入场用 `IntersectionObserver`，监听器不生效时 1.5 秒后兜底全部显示。打字机有 3 秒兜底（后台标签页会把定时器节流）。首屏点阵是事件驱动的——鼠标划过才重绘，平时不耗 CPU。
- **一个坑**：横向溢出裁剪必须放在 `html` 上（`overflow-x: clip`）。放在 `body` 上会让 body 自己变成滚动容器，Safari / 内嵌 WebView 里窗口滚动会失效。
- **另一个坑**：后台标签页里 `requestAnimationFrame` 可能永远不触发，凡是"画一帧"的代码都要在脚本里**同步先画一次**，再用定时器驱动后续动画。

## 技术说明（给你后面找的人看）

- **三维装箱演示**：物品按高度降序，货架式装填（行内沿 x、行间沿 z、层间沿 y），装载率按实际摆放体积实时计算；等距投影的绘制顺序按 (x+y+z) 从后往前。物品清单在源码 `ITEMS` 数组里，改尺寸即可换演示数据。
- **知识库问答演示**：预设三组问答存在按钮的 `data-q / data-a / data-c` 属性里，点击后打字机输出（2.6 秒兜底，后台标签页定时器被节流时直接显示全文）。要换演示文案改这三个属性即可。
- **路线规划演示**：`haversine` 球面距离 + 贪心最近邻 + 随机打乱重启（与算法说明里 `generate_multiple_paths` 的思路一致），候选数按点位数自动调整（≤4 个给 2 条，否则 10 条）。底图海岸线是按点位动态生成的示意装饰，非真实地图。
- 全部交互（菜单、放大、复制邮箱、两个算法演示）无任何外部依赖。
