# 团队介绍页（给第三方看）

**线上地址：https://zephyrgq.github.io/team-intro/**
（GitHub Pages，推送 `main` 分支后约 1 分钟自动更新）

## 文件

- `index.html` — 整个页面就这一个文件。样式、脚本、**10 张证书**和**2 张界面截图**全部以 base64 内嵌，不依赖任何外网资源，也不依赖旁边的文件夹。
  当前约 **1.3 MB**，微信发送、U 盘拷贝、内网打开都不会丢图。
- `ui/` — 按项目源码画的界面原型（装箱 / 观鸟小程序），只作素材来源，不参与部署
- `shots/` — 2 倍分辨率截图（3360×2100），可直接放进 PPT
- 部署只需要 `index.html` 一个文件。

## 怎么打开

双击 `index.html` 就能用浏览器打开。断网也能开，内网环境也能开。

要发给别人（政府单位、合作方）：

- 微信发送时选「以文件方式发送」，对方点开就能看，不需要装任何东西。
- 放进网站服务器时，文件名保持 `index.html` 即可，不用改配置。

本地起服务预览（可选，改了代码建议用它，避免浏览器缓存）：

```powershell
python -m http.server 8123
# 然后打开 http://127.0.0.1:8123/
```

## 知识产权证书

- **10 张**：发明专利 3 张 + 软件著作权 7 张
- 图片是客户在 PS 里处理过的版本：**著作权人 / 专利权人 / 地址 / 发明人已打码**，名称、登记号、证书号、钢印保持清晰
- 每张压到 **560px 宽 / WebP q74**（27–55 KB），跑马灯 60 秒一圈、无缝循环，悬停暂停
- 换图流程：新图放到 560px 宽 → 转 WebP → base64 → 替换 `index.html` 里对应 `<img class="ip-photo" src="data:image/webp;base64,...">` 的内容。
  注意跑马灯是「内容写一份、运行时克隆第二份」，**只需改一份**，克隆会自动跟随。

## 设计约定（改样式前先看）

- **配色**：暖白纸底 `#F6F4EE` + 墨色 `#151614`；`--ink-2 #45473F` 正文、`--ink-3 #65675C` 辅助（面板底上 4.98:1，过 WCAG AA）；雾蓝 `#5B8FD9` 只做活体指示。
- **字号阶梯**（2026-10 统一，共 5 级 + 4 档 fluid 标题）：

  ```
  10px 图内标签 / 11px 等宽微标签 / 13px 注释 / 14.5–15px 正文 / 16px 强调与小标题
  标题：18–21（h3）/ 28–42（h2）/ 38–74（首屏）/ 20–26（数字）
  ```

- **字距 4 档**：`-.015em`（大标题）/ `.01em`（正文）/ `.05em`（小标签）/ `.16em`（等宽 eyebrow）
- **行高 5 档**：`1` / `1.15` / `1.6` / `1.75` / `1.9`
- **字体**：只用系统字体（苹方 / 微软雅黑）+ 系统等宽，不加载外网字体
- **动效**（全部原生实现，无 anime.js 之类依赖）：
  - 顶部滚动进度条（`scaleX`）
  - 区块标题遮罩揭示（`clip-path`）
  - 首屏字符画滚动放大 1 → 1.28 + 指针视差（`--zoom` / `--mx` / `--my` 三个 CSS 变量）
  - 交付流程随滚动点亮（描边数字 → 实心，轨道墨线跟着长）
  - 卡片入场错峰（`IntersectionObserver`）
  - **`prefers-reduced-motion` 全部关闭**，静止展示

## 两个踩过的坑（别踩第二次）

1. **横向溢出裁剪必须放在 `html` 上**（`overflow-x: clip`）。放 `body` 上会让 body 变成滚动容器，Safari / 内嵌 WebView 里窗口滚动会失效。
2. **后台标签页里 `requestAnimationFrame` 可能永远不触发**，凡是"画一帧"的代码都要同步先画一次，再用定时器驱动后续动画。

## 技术说明（给后面接手的人）

- 样式全部在 `<style>` 内，按 `/* ============ 区块 ============ */` 分段；脚本在文末一个 IIFE 里，按功能注释分段。
- **三维装箱演示**：物品按高度降序，货架式装填（行内沿 x、行间沿 z、层间沿 y），装载率按实际摆放体积实时计算；等距投影绘制顺序按 (x+y+z) 从后往前。物品清单在源码 `ITEMS` 数组里。
- **路线规划演示**：`haversine` 球面距离 + 贪心最近邻 + 随机打乱重启；底图海岸线是按点位动态生成的示意装饰，非真实地图。候选路线列表已按需求移除，只保留地图与统计指标。
- **案例区高度**：脚本量各屏自然高度取最大值，只在 `resize` / 字体加载后重算，切屏不重排。
- 全部交互（菜单、复制邮箱、两个算法演示、证书跑马灯）无任何外部依赖。

## 打印和转 PDF

直接 Ctrl/Cmd + P。页面自带打印样式：自动转白底黑字，去掉按钮、顶部滚动条和首屏字符画；装箱三维图、分层图、路线图以静态结果一起打印，联系区深色卡片自动转白底描边。入场动画元素在打印时强制显示，不用先滚到底。
