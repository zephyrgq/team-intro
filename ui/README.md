## 三套界面分别是什么

**packing.html｜三维装箱优化系统**
深色工程界面。左边是参数面板，用的是你们代码里的真实参数名：`bigger_first`（大件优先）、`fix_point`（重力固定）、`check_stable`（稳定性校验）、`support_surface_ratio`（可支撑面积比例）、`binding`（组合打包）、`distribute_items`（多箱分配）。中间是三维装箱结果，可以**按住鼠标拖动旋转**、滚轮缩放、用「分层展开」把每一层拉开看内部。

装载率、支撑率、重心偏移都是浏览器里实时算出来的，不是写死的数字。求解用的是：极值点候选位置 → 重力下坠 → 支撑面积校验，再对四种排序各跑一遍取最优。默认箱型 900×700×600，结果 15 件入箱、1 件进第二箱、装载率 67.6%。

**yinbao.html｜融资担保与授信管理平台（已脱敏）**
浅色后台管理界面，仿 Element Plus 风格。左侧菜单、顶部面包屑、四张额度指标卡、授信台账表格、筛选栏、分页，右侧是审批流程和放款用信。
界面里的单位名已全部替换为通用名：产业集团 / 建设子公司 / 物流子公司 / 制造子公司，没有出现任何真实客户字样。

审批流那条时间轴是这套系统最有说服力的地方，六层审批全部来自你们源码里的真实字段：**子公司党委会 → 子公司董事会 → 公司党委会 → 公司董事会 → 集团党委会 → 集团董事会**，前三层已通过、第四层进行中。担保信息里的字段也全是真名：担保单位、被担保单位母公司、担保金额、担保方式、担保事项、收函金额、国资委备案表等。

**bird.html｜观鸟小程序**
三部手机并排：首页、拍照识别、识别结果。底部四个 tab（首页 / 发现 / 鸟库 / 我的）用的是小程序 `pages/images` 里的**原始图标**。识别结果页写的是丹顶鹤，因为盐城黄海湿地是丹顶鹤越冬地，和你们的项目背景一致。
界面里的鸟类照片是**真实照片**（替换了早期手绘剪影），存在 `ui/assets/` 下，全部来自 Wikimedia Commons、CC BY-SA 授权，逐张版权信息见 `bird.html` 文件末尾的注释。正式对外前建议换成自有版权素材：直接替换 assets 下的同名文件即可。

## 必须注意的一件事

**页面里的数据全是编的**，只用于演示界面长什么样：

- 授信后台：42,600.00 万元授信总额、各家银行名称、张明 / 李建国 / 王海涛这些人名，**都是虚构的**（单位名已脱敏为"产业集团"等通用名）；
- 装箱：16 件货物的名称和尺寸是示例；
- 观鸟：观测记录、坐标、置信度 96.2% 都是示例。

这些图**不能**直接拿出去当成真实业绩佐证。要对外用，有两个选择：

1. 把示例数据换成你们真实的、可以公开的数据；
2. 或者只当"系统长这样"的能力示意，明确说明是演示界面。

需要换成真实数据、或者调整配色和模块，告诉我改哪里就行。

## packing.html 的隐藏参数

地址栏加参数可以直接定格到指定视角，方便反复出图：

```
packing.html#explode=85&rot=-32,-48
```

`explode` 是分层展开百分比（0 到 100），`rot` 是俯仰角和水平角。截图里的 `packing-explode.png` 就是这么来的。
